## WASM build

`d2.wasm` is built locally from the pinned source with the recipe recorded in
`tools/d2/d2-package.lock.json`; the built artifact SHA-256 is
@@D2WASMSHA256@@. The recipe, rendered from the lock:

@@BUILDRECIPE@@

The lock pins the Go toolchain and wasm-opt (binaryen) versions together with
the expected built-artifact digest, so `make d2-renderer-package-check`
re-derives the exact bytes. The v0.8.2 build is the first with pure-Go layout
engines (dagro and elk-go replaced the JavaScript runners), which is what
keeps this package free of JavaScript `eval`.

`wasm_exec.js` is the Go Authors' WebAssembly JavaScript runtime support file
and carries its own BSD-3-Clause license notice in its header; its SHA-256 is
@@WASMEXECSHA256@@.

## Fonts

The module embeds the Source Sans Pro, Source Code Pro, and Fuzzy Bubbles
typefaces (SIL Open Font License 1.1) and subsets them into every rendered
SVG. See `THIRD_PARTY_NOTICES.txt`, which is upstream's own notices file for
this artifact, copied verbatim.
