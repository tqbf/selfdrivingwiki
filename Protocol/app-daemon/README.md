# App–daemon wire contract (gRPC)

Language-neutral contract between the Swift app and the bundled `wikid`
daemon, served over a local Unix domain socket with gRPC. A Rust peer uses
the same schemas to prove the contract is language-neutral.

## Layout

- `proto/wikid/appdaemon/v1/*.proto` — the schemas. Package version is the
  last package segment; wire-incompatible changes mint a new package
  version (`v2`), never edit history in place.
- `buf.yaml` — lint + breaking-check configuration.
- `baseline/image.binpb` — last accepted descriptor image; `make
  check-app-daemon-proto` rejects schema edits that break it. Update only
  after compatibility review: `make update-app-daemon-proto-baseline`.
- `tools.lock.json` — pinned download URLs and SHA-256 digests for protoc,
  the Swift codegen plugins, and Buf. `make app-daemon-tools` installs and
  verifies them.
- `generated/swift/` — committed generated Swift (regenerated by the make
  target; drift fails the check).

## Semantic rules (apply to every schema)

1. **ID namespaces are distinct wrapper messages** (`WikiId`, `PageId`, …).
   The raw value is the existing ULID string — the wrapper carries the
   namespace in the type system, it does not change the bytes.
2. **Time is `google.protobuf.Timestamp`.** Never epoch millis in a payload.
3. **Enum value 0 is the unknown/unspecified member.** Senders never send it
   deliberately. Receivers must map any unrecognized numeric value to the 0
   member and fail as a typed `unknown variant` — never guess.
4. **Presence is explicit.** Optional fields use `optional`; absence is never
   a `""`/`0` sentinel.
5. **Removed fields reserve both the number and the name** in the same edit.
   Never renumber, never change a field type, never convert singular to
   repeated.
6. **Oneofs evolve by adding variants only,** and boundary code dispatches
   exhaustively — never an operation string plus opaque bytes.
7. **Bounds:** a single message must stay under 4 MiB. Larger payloads chunk
   across calls; receivers reject oversize with `RESOURCE_EXHAUSTED`.

## Transport and admission rules

- The listener binds `g/s` under a mode-0700 directory inside the App Group
  container. No TCP listener exists. Socket-path length is checked against
  the full `sockaddr_un` byte limit before bind; on overflow the daemon
  fails with a typed error — never truncation, never a path outside the
  container.
- A process-lifetime exclusive `flock` is taken before bind (same pattern as
  the CLI search socket). A second live listener fails with a typed
  ownership error and never unlinks a served socket; a stale socket whose
  guard process died is provably ownerless and safe to remove.
- Authentication is a 256-bit opaque bearer credential issued over XPC
  admission, sent as gRPC `authorization` metadata. Socket permissions alone
  are not authentication. The credential binds to one XPC connection and one
  daemon instance; XPC invalidation revokes it and terminates its streams.
  Credentials live only in process memory.
- A short-lived (30 s) bootstrap credential is exchanged once for the
  session bearer. Exchange is idempotent within the window: the same
  unexpired credential returns the same bearer.
- gRPC retries and hedging are disabled. Clients implement bounded backoff
  only for bootstrap and subscription recovery; mutations are never
  auto-retried on ambiguous failures.

## Transport-specific exclusions

- No TCP transport, no TLS, no remote peers: this is a same-machine,
  same-user, App-Group-scoped channel.
- The existing CLI domain socket (`SearchSocketWire` framing) and the File
  Provider socket protocols are separate transports. They keep their framing,
  admission, and lifetime rules unchanged; nothing from this contract
  replaces or tunnels through them.
- Linux keeps the daemon's stdio JSON-RPC transport; this contract is
  macOS-only.
